# Evidence report layout

The canonical closeout is assembled from the current release audit, claim map, split receipts, baseline reports, and the 2026-08-12 remediation manifest. Reports with `current_` or the current revision suffix are submission-facing local evidence. Files under `probes/`, dated review snapshots, and historical benchmark directories are retained as provenance only and must not be used to upgrade a claim without a fresh hash-bound replay.

The local candidate remains gated by the raw scenario/candidate ledgers, completed double review, public repository and DOI, and final author metadata. A report marked `pass` therefore means that its declared local contract passed; it does not imply independent physical truth or public availability.
